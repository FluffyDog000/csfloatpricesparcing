# Уведомления о выгодных лотах на BuffMarket — вводная для отдельной сессии

Отдельный сервис, который смотрит лоты на BuffMarket и пишет в Telegram, когда
лот дешевле рынка или у него дорогой float по обычной цене. «Рынок» — база
этого бота (история продаж CSFloat). Сам CSFloat-бот при этом не меняется.

## Рамки

- **Один аккаунт, один постоянный адрес, обычный темп.** Без ферм аккаунтов,
  ротации кук и прокси ради обхода лимитов площадки. Если сайт ограничивает —
  сокращаем список или частоту, а не размножаем аккаунты.
- Официального API у BuffMarket нет; берём тот же запрос, что делает браузер
  на странице предмета (список лотов предмета, «недавно добавленные»).
- Лента новых лотов есть только внутри предмета, не по всему рынку, поэтому
  опрос идёт по списку предметов. Список — те, где выгода реальна (ликвидные,
  с ощутимой премией за float), с расписанием как у сборщика: ликвидные чаще,
  редкие реже.

## Что брать из базы этого бота

SQLite, путь — `CSFLOAT_DB_PATH` (по умолчанию `data/csfloat_sales.db`).
Открывать **только на чтение** (`file:...?mode=ro`, WAL допускает чтение
параллельно со сборщиком).

- `items(id, market_hash_name, active, ...)` — какие предметы отслеживаются.
- `sales(item_id, market_hash_name, price, float_value, paint_seed,
  paint_index, sold_at, ...)` — история продаж CSFloat, USD, время ISO UTC.
  Не удаляется никогда.

Готовые функции (импортировать из `src/`, не копировать):

- `src/profit.py: estimate(sales, float_value)` — медиана продаж в сотой
  float лота (или всего предмета, если в сотой мало продаж) и текст «как
  оценено».
- `src/recency.py: to_today(rows, window)` — привести старые продажи к
  сегодняшнему уровню цены (строкам нужен `age_days`).
- `src/phases.py` — фазы Doppler: имя → настоящее имя + `paint_index`.
- Паттерновые скины (Fade, Marble Fade, Case Hardened, Crimson Web): цена от
  паттерна, медиана по float обманывает — не уведомлять или отдельный порог.

## Сигналы

1. **Дешевле рынка:** цена лота (в USD, с курсом и комиссией BuffMarket) ниже
   медианы его сотой float на N% (настройка, по умолчанию 15–20%), с учётом
   комиссии CSFloat 2% при перепродаже.
2. **Дорогой float по обычной цене:** float в сотой, где медиана заметно выше,
   чем у соседней «обычной» сотой, а цена лота — как у обычной.

Уведомление: предмет, float, паттерн, цена, ожидаемая цена на CSFloat,
выгода после комиссий, на чём оценено (сколько продаж, за сколько дней),
ссылка на лот. Повтор по тому же лоту — не чаще раза.

## Где жить коду

Тот же репозиторий, отдельная папка (`buff/`) и отдельный systemd-сервис:
база и функции из `src/` под рукой, CSFloat-бот не затрагивается.
